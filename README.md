# 📚 Temel Kavramlar — İslami Terimler Sözlüğü

İslami ve dini temel kavramları, terimleri ve tabirleri açıklayan bir başvuru uygulamasıdır. Öğrenciler ve meraklılar için pratik bir dini sözlük sunar.

## ✨ Özellikler

- 📖 Kapsamlı İslami kavramlar sözlüğü
- 🔍 Hızlı arama
- 📑 Kategorilere göre filtreleme
- 🔖 Sık kullanılanlar ekleme
- 📱 Android APK (Capacitor wrapper)
- 📴 Çevrimdışı çalışma

## 🛠️ Teknolojiler

| Katman | Teknoloji |
|--------|-----------|
| Frontend | HTML5, CSS3, JavaScript (Vanilla) |
| Mobil Wrapper | Capacitor 6.x |
| Platform | Android APK |

## 📋 Gereksinimler

- Node.js 18+
- Android Studio
- Java 17+
- Android SDK 21+

## 🚀 Kurulum

```bash
npm install
npx cap sync android
npx cap open android
```

### APK Derleme
```powershell
.\apk_yap.ps1
# veya
.\apk_yap.bat
```

## 📁 Proje Yapısı

```
├── www/              # Web uygulaması (HTML/JS/CSS)
├── android/          # Android native proje
└── package.json
```
